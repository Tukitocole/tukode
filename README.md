# Tukode

Landing y portfolio de Tukode, desarrollado con React, Vite y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

Copiá `.env.example` como `.env` y reemplazá `VITE_WHATSAPP_NUMBER` por el número comercial completo, sin `+`, espacios ni guiones.

## Producción

```bash
npm run build
```
